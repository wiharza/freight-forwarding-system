# 0008 — Master tarif berversi dengan status verifikasi hukum; blokir di filing

Konteks: master tarif dan mapping hukum (MFN per HS, preferensi FTA per skema, lampiran PPh 22, daftar barang mewah PPN & PPnBM) berubah lewat PMK, dan sebagian isi seed riset masih [PERLU VERIFIKASI] terhadap PDF resmi JDIH. Keputusan: tiap item master membawa status Terverifikasi / Perlu Verifikasi; draf estimasi boleh memakai item Perlu Verifikasi dengan label peringatan; Snapshot PIB untuk filing memblokir item tersebut. Setiap update tarif diajukan dengan alasan + dasar hukum tercatat dan tidak boleh disetujui pembuatnya sendiri (ADR 0006). Alternatif yang ditolak: menganggap seed lengkap atau warn-only — tarif yang salah berarti denda dan selisih pajak.

Konsekuensi: seed mapping PPh 22 Lampiran A/B harus dibangun dari PDF lampiran PMK 51/2025 resmi sebelum produksi; aturan ambang PPnBM (PP 73/2019) nonaktif sampai terverifikasi; flag barang mewah, pengecualian PPh 22, dan pembulatan bekerja per Seri Barang; urutan pengecekan PPh 22 dikunci (Lamp. A → Lamp. B → khusus 0,5%/0,25% → umum 2,5% dgn API / 7,5% tanpa API → kasus lelang 7,5% dari harga jual lelang); Total Pungutan = BM + PPN + PPh 22 + PPnBM + pungutan lain (mis. BMAD/BMTP) bila ada; CIF Rupiah disimpan presisi penuh di snapshot sampai aturan pembulatannya dikonfirmasi ke CEISA.
